# بهروز VPN

پروژه اندروید از صفر — رابط فارسی سبز/مشکی، مبتنی بر WireGuard.

## امکانات موجود در این نسخه
- رابط فارسی و راست‌چین
- افزودن پروفایل WireGuard از فایل `.conf`
- فهرست پروفایل‌های واردشده
- انتخاب دستی پروفایل
- انتخاب هوشمند بر اساس آزمون دسترسی/تأخیر endpoint (هرجا شبکه اجازه دهد)
- اتصال و قطع واقعی از طریق کتابخانه رسمی WireGuard Tunnel
- بدون سرور اختصاصی و بدون کلید یا سرور ساختگی

## نکته مهم درباره سرور رایگان
این برنامه عمداً هیچ کلید خصوصی یا سرور عمومی ناشناس را داخل خود قرار نمی‌دهد. سرورهای رایگان عمومی ممکن است اپراتور ناشناس داشته باشند و از نظر حریم خصوصی تضمین‌شده نیستند. برای اتصال واقعی باید پروفایل معتبر WireGuard (`.conf`) وارد شود. VPN Gate عمدتاً پروتکل OpenVPN ارائه می‌کند و فایل‌های آن مستقیماً پروفایل WireGuard نیستند؛ بنابراین این نسخه آن‌ها را به‌اشتباه به‌عنوان WireGuard نمایش نمی‌دهد.

«انتخاب هوشمند» در این نسخه یک امتیازدهی محلی و قابل‌توضیح بر اساس آزمون شبکه است، نه هوش مصنوعی ابری و نه تضمین امنیت. در نسخه بعدی می‌توان منبع سرورهای WireGuard معتبر را اضافه کرد، پس از بررسی مجوز، پایداری و امنیت منبع.
