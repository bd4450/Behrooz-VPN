# Behrooz VPN

اپلیکیشن اندرویدی فارسی با پوسته سبز و مشکی.

## وضعیت این نسخه

این بسته **نسخه آغازین رابط کاربری** است و هنوز VPN واقعی برقرار نمی‌کند.
دکمه اتصال عمداً پیام راهنما نشان می‌دهد تا برنامه ادعای اتصال بدون سرور و
پیکربندی معتبر نداشته باشد.

## فناوری

- Android / Kotlin
- حداقل Android 6 (API 23)، مناسب Android 12
- کتابخانه رسمی قابل‌جاسازی WireGuard از Maven Central
- ساخت APK آزمایشی با GitHub Actions

## گام‌های بعدی

1. افزودن ورود امن فایل پیکربندی WireGuard با پسوند `.conf`
2. پیاده‌سازی چرخه عمر تونل با `VpnService` و کتابخانه WireGuard
3. افزودن فهرست سرورهای رایگان فقط از منابع معتبر و قابل‌بررسی
4. آزمایش اتصال، DNS، قطع امن و نشت ترافیک
5. افزودن انتخاب هوشمند بر اساس latency و دسترس‌پذیری

**توجه:** سرور VPN از داخل برنامه تولید نمی‌شود. برای اتصال، به سرور فعال
و اطلاعات پیکربندی معتبر نیاز است. اطلاعات خصوصی، کلید خصوصی یا فایل
پیکربندی واقعی را در مخزن عمومی GitHub قرار ندهید.
