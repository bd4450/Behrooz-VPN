
# Behrooz VPN

Behrooz VPN is a real Android VPN application.

## Project Information
- App Name: Behrooz VPN
- Package Name: com.behrooz.vpn
- Platform: Android
- Minimum Android: 8.0
- Target Device: POCO X3 Pro
- Android Version: 12
- Programming Language: Kotlin
- Build System: Gradle
- Build Platform: GitHub Actions
- Development Device: Android Phone

## Main Features
- Real VPN connection
- Connect and Disconnect buttons
- Connection status
- Connection timer
- Server selection
- Add private server
- Free trusted server support
- Persian and English interface
- Simple and beautiful design

## VPN Protocols
- WireGuard
- OpenVPN

## Security
- Secure encryption
- No fake servers
- No fake connection status
- No unauthorized data collection
- DNS leak protection
- Trusted VPN servers only

## Build
The APK must be built automatically using GitHub Actions.

The application must be tested and fully functional.

## Important Requirements
- No computer required
- No Termux required
- Free development tools
- Complete and working source code
- Android 12 compatibility

## Final Goal
Build a real, secure, stable and free Android VPN application named Behrooz VPN.
